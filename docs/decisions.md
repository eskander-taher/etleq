## Design & shell (workstream B)

- **Contrast audit (computed, WCAG 2.x).** All brief pairs pass except two that the brief didn't list: `ignition-700` on `sand-100` = 4.48:1 and `verified-600` on `sand-100` = 4.34:1 (both fail AA for small text). Suggested token change for the lead (globals.css is lead-owned): `ignition-700` → `#BC3F0B` (4.72:1 on sand-100, 5.10:1 on sand-50) and `verified-600` → `#147638` (4.94:1 / 5.34:1). `/design` shows every pair with its live ratio.

One colour by default (`currentColor`), the dot can be ignition. It's never mirrored in RTL. `Logo` has the variants `ar`, `en`, `stacked` and `mark`, so swapping the final logo means changing one file. The SVG lockups in `public/` use live Alexandria text; outline them before using them outside the site. `src/app/icon.svg` (favicon) and `src/app/apple-icon.png` show the ignition mark on ink. `public/logo.png` (512px) exists because E's `organizationNode` references `/logo.png`.

- **Announcement bar.** It shows only when `enabled`. If the text uses `{n}`/`{total}` and either `slotsLeft` or `slotsTotal` is empty, the bar is hidden rather than showing an invented number.
- **Fallback header nav** follows brief row 1: Launch 30, Models, Solutions, Projects, Blog, About. The CMS `header.nav` replaces it entirely when set.
- **Language switcher** is a plain `<a hrefLang>`, so `<html lang dir>` reloads cleanly. It swaps the `/en` prefix by default. Pages override the target with `<SetAlternatePath ar en note />` (React context in `components/layout/alternate.tsx`) or the `alternateHref` prop. With `note`, the switcher gets an accessible description (and a visible one in the mobile menu) saying the page doesn't exist in that language yet.

While visible it adds `padding-block-end` to `body` and `scroll-padding-block-end` to `html`, so it never covers focused elements (WCAG 2.4.11). It's `inert` when hidden.
- **Breadcrumbs** prepend Home automatically and pass absolute-or-locale-less hrefs to E's `breadcrumbNode(items, locale)`. Use `jsonLd={false}` when the page already includes a BreadcrumbList in its own graph, and `locale` to force a language (used by `/design`).

- **Form primitives** (`components/ui/form.tsx`): `<Field>` owns the ids and passes them through context, so `Input`, `Textarea`, `Select` and `Checkbox` get `aria-describedby` (hint plus error), `aria-invalid` and `aria-required` automatically. Error colour is `#B42318`, about 6.5:1 on white.

With none published, a dashed "development only" placeholder shows outside production, and the section is omitted in production.

## SEO, GEO & analytics (workstream E)

- 2026-10-16 — `buildMetadata` sets `title: { absolute }` after applying the template itself (seo-defaults `titleTemplate`, passed in as `titleTemplate`, else `%s — إطلاق` / `%s — Etleq`), so layouts must not add a second template. Titles already containing the brand are not re-branded. hreflang (`ar`, `en`, `x-default`→Arabic) only when `alternates.ar && alternates.en`. Staging always gets `robots: noindex, nofollow` (plus Nginx `X-Robots-Tag`).
- OG images: `/og.png?locale=&title=&subtitle=` (route `src/app/og.png/route.tsx`). The path has a dot on purpose: the next-intl proxy matcher skips dotted paths, so `/og` would have been rewritten into `[locale]`. Tested satori (next/og 16.4.2) with Alexandria from Google Fonts (TTF via the CSS API `text=` subset): Arabic letters **join** correctly, but satori does no bidi reordering, so the title is laid out word by word in a wrapping `row-reverse` flex row, and mixed tokens (e.g. `ر.س`) are split into runs. Two known limits: (1) word gaps are uneven because satori measures Arabic advances before shaping; (2) with more than one font registered satori's fallback resolver crashes on shaped Arabic glyphs, so Arabic cards use a single font (Alexandria 700). If cards ever need pixel-perfect Arabic, the fallback is: on publish, render `/og-preview?...` (an HTML page) with Playwright at 1200×630, upload to `Media` (`og` size) and set `meta.image`, which `buildMetadata` already prefers over the generated card.
- Sitemaps: `src/app/sitemaps/sitemap.ts` with `generateSitemaps` (ids = section names) → `/sitemaps/sitemap/<section>.xml`; `/sitemap.xml` is a hand-written sitemap index route (Next does not generate one for `generateSitemaps`). Static pages carry no `lastModified` (a fake build-time date is worse than none). Samples are included outside production only. Queries talk to Payload directly via `src/components/seo/server-data.ts` with an 8 s timeout and return `[]` when MongoDB is unreachable, so builds without a DB still emit static entries.
- robots: `src/app/robots.ts` (`revalidate = 300`) reads `seo-defaults.aiCrawlers`. Googlebot/Bingbot are always allowed (blocking them would deindex the site); `allowSearch` governs OAI-SearchBot, OAI-AdsBot, PerplexityBot, Claude-SearchBot; `allowUser` governs ChatGPT-User, Perplexity-User, Claude-User; `allowTraining` governs GPTBot, ClaudeBot, Google-Extended. Missing toggles = allow. Every group repeats the disallow list because a matching UA group replaces `*`.
- RSS: `/rss.xml` → `src/app/rss.xml/route.ts` (Arabic); `/en/rss.xml` → `src/app/(frontend)/[locale]/rss.xml/route.ts` with `generateStaticParams = [{locale:'en'}]`, `dynamicParams = false`, and a 404 for any other locale. A top-level `src/app/en/` folder was avoided so the `[locale]` tree stays the only owner of `/en/*`.
- Consent: basic mode, cookie `etleq_consent` = `{categories, at, policyVersion}` (180 days); `POLICY_VERSION` in `src/lib/consent.ts` — bump it when the cookie/privacy policy changes. Tags are injected by hand (not `@next/third-parties`) so Consent Mode v2 `default: denied` runs before `update` in the same tick and nothing loads before a choice. Revoking a granted category reloads the page to unload scripts. Clarity: set masking to **Strict** in the Clarity project; the loader also refuses `/admin`. Footer link: `openConsentSettings()` or `window.dispatchEvent(new Event('etleq:open-consent'))`.
- Analytics: `trackEvent` lives in the client-safe `src/lib/analytics.ts` and returns the `event_id`; server events live in `src/lib/analytics-server.ts` (`sendServerEvent`) because they need `node:crypto` and secrets — the contract's "`@/lib/analytics` exports sendServerEvent" is superseded. Ad-platform mapping (`AD_EVENT_MAP`): generate_lead → Meta Lead / Snap SIGN_UP / TikTok SubmitForm; booking_scheduled → Schedule / RESERVE / Schedule; close_convert_lead → Purchase / PURCHASE / CompletePayment; others in the table. PII keys are stripped before pixel calls; CAPI hashes email/phone with SHA-256. Outside `SITE_ENV=production` server events are logged, not sent.
- CI: MongoDB runs via `docker run mongo:8.0 --replSet rs0` + `rs.initiate`, because GitHub service containers cannot pass a command. CI builds with `SITE_ENV=development` so Lighthouse can score SEO 100 (staging would emit noindex). Lighthouse runs the default mobile profile per brief §14. Playwright screenshot specs are skipped in CI until baselines are committed (`tests/e2e/*-snapshots`).
- Deploy: staging = git checkout + `pm2 reload`; production = release dirs + `current` symlink, so rollback is switching the symlink and `pm2 reload` (docs/deploy.md).

## CMS (workstream A)

- **Additive fields (not in the contract, nothing renamed):** `private-files.purpose` (`cv` / `consent`, required, default `cv`) and `private-files.note`, so recruiters only see CVs and editors only see consent records; `leads.anonymisedAt` and `applications.anonymisedAt` (set by the retention job); `short-links.isSample`. Every contract field name and slug is used exactly as written.
- **Drafts everywhere `translated` exists.** Pages, models, solutions, projects, posts, news, guides, jobs, faqs and authors have drafts + autosave (800 ms) + `schedulePublish`; categories and tags have plain drafts. This gives them all `_status`, so `publicWhere()` works for every collection with a `translated` group. Testimonials have no `_status`: anonymous readers only get `verified: true`, and `verified` can only be ticked once a consent file is attached.
- **Querying `translated.<locale>`: use `overrideAccess: true` (the Local API default).** Payload reads a trailing locale code in a query path as a locale selector, so a user `where` on `translated.en` with `overrideAccess: false` fails with "path cannot be queried: translated". With the default `overrideAccess: true` it filters correctly (verified against MongoDB). `findPublic` / `findBySlug` therefore run with `overrideAccess: true`; `publicWhere` already enforces published + translated (+ non-sample in production). Collection read access for anonymous users still returns the same constraint (access-returned `where` is not affected).
- **Home page** is the `pages` document with slug `home` (path `/`). Layout block slugs: `hero`, `proofStrip`, `problem`, `mechanism`, `modelsTeaser`, `offerStack`, `howItWorks`, `guarantee`, `founders`, `projectsProof`, `faqList`, `finalCta`, `richContent`, plus the rich-text blocks. Rich-text block slugs (Lexical `block` nodes, `fields.blockType`): `callout`, `statWithSource`, `comparisonTable`, `faq`, `cta`, `video`. Interfaces: `CalloutBlock`, `StatWithSourceBlock`, `ComparisonTableBlock`, `FaqBlock`, `CtaBlock`, `VideoBlock`, `HeroBlock`, etc.
- **Guide publish gate** uses `sources[]` (url + accessedAt) instead of `factSources`, and `content` instead of `gulfVersion`, because guides have neither field in the contract. Models: answerBox, ≥3 factSources with url + checkedAt, gulfVersion, whyItWorks, ≥1 fitCriteria, reviewer, lastReviewedAt, and an MRR amount needs `sourceUrl` + `reportedAt`. Gates run per ticked locale; localized fields of the other locale are read from the stored document (latest draft). Errors are `ValidationError`s with one field-level message per problem.
- **Translation gate required fields:** pages `title`; models `title, answerBox, whatItDoes`; solutions `title, summary`; projects `title, context`; posts `title, excerpt, content`; guides `title, excerpt, answerBox, content`; news `title, excerpt`; jobs `title, description`; faqs `question, answer`; authors `name, role, bio`; categories/tags `name`.
- **Slugs:** generated from the English title (when only an Arabic title exists, a temporary `draft-xxxx` slug is used and replaced by the English one until first publish). Unique with `-2`, `-3`. A slug or section change on a published doc writes 301s in `redirects` for `/x/old` and `/en/x/old` (custom URL type), removes any redirect that would loop, and repoints older redirects to the new path.
- **Revalidation:** `revalidateDoc()` revalidates both locales' detail paths (old and new), section indexes, home, `/sitemap.xml`, `/rss.xml`, `/en/rss.xml`, `/llms.txt`, and tags `<collection>` and `<collection>:<slug>` (Next 16 `revalidateTag(tag, 'max')`). Globals revalidate tag `global:<slug>` and the root layout. Autosaves on a live doc do not revalidate or ping. IndexNow and Google Indexing (jobs only) are dry-run logs unless `SITE_ENV=production` and the key/service account are set; the Google call uses a JWT signed with `node:crypto`, no extra dependency.
- **Retention:** leads `retainUntil` = now + `site-settings.retention.leadsMonths` (24), refreshed when the status changes (last contact); applications + `applicationsMonths` (12), restarted when the status becomes `hired`/`rejected`. Task `anonymiseExpired` is scheduled daily at 02:30 on queue `retention`; `autoRun` checks that queue hourly in the Node server. Scripts set `DISABLE_JOBS_AUTORUN=true`. The job blanks personal fields and deletes the CV file.
- **Uploads:** `private-files` accepts `application/pdf` only; Payload's own type sniffing rejects renamed files, and our `beforeValidate` hook also checks the `%PDF-` signature and the 5 MB limit. Local disk dirs: `media/` and `private-media/` (both git-ignored). With `S3_BUCKET` set, media goes to the public bucket with `disablePayloadAccessControl` (and `S3_PUBLIC_URL` for CDN URLs). With `S3_PRIVATE_BUCKET` set, private files use signed downloads (5 minutes).
- **Admin visibility:** leads/subscribers are hidden from non-sales roles, applications/jobs from non-recruiter roles, and private files from sales. Access is enforced by the access functions in any case; hiding only tidies the UI.
- **Seed:** `pnpm seed` wipes public content collections plus `short-links` and `redirects` (never leads, applications, subscribers or other users), creates or resets `admin@etleq.local` (password from `SEED_ADMIN_PASSWORD`, default `etleq-dev-123`), and writes each document in Arabic and then English. Array row ids are copied across locales so localized sub-fields stay on the same rows. Seed context: `{ seed: true, disableRevalidate: true, skipSlugRedirects: true }`; publish gates are skipped when `context.seed` is set.
- **check-samples:** 5 s MongoDB server-selection timeout (`MONGO_SERVER_SELECTION_TIMEOUT_MS`, default 10 s in the app), plus a start-up allowance for loading the config. If the database can't be reached, it fails only when `SITE_ENV=production`.
- **dev-mongo fallback** runs on port 27019 by default (`DEV_MONGO_PORT`). It leaves 27017 alone because that port may be a system MongoDB service, and 27018 is the Docker replica set.
- **Admin languages:** Payload ships Arabic translations, so the admin UI offers Arabic and English. `fallbackLanguage` is `en`.
